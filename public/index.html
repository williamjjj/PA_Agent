MARKET DATA
导入 K 线数据
上传 50–500 根已收盘 K 线。文件不存储在服务器中。
列名：time,open,high,low,close,volume
时间按升序排列；支持 Unix 秒 / 毫秒、ISO 日期（默认 UTC）。

  
PRIVATE WORKSPACE
解锁 AI 分析
输入管理员设置的访问口令。不是模型 API Key，口令不会保存在浏览器存储中。

  
GETTING STARTED
使用指南
  1. 准备数据
    导入 50–500 根升序排列、已收盘的 OHLCV 数据，并确认周期和品种。示例图表不代表真实行情。
  2. 解锁分析
    管理员在服务端设置至少 24 个字符的随机访问口令 PA_WEB_ACCESS_SECRET。通过口令验证后，会话有效期为 8 小时。
  3. 阅读结果
    阶段一识别结构，阶段二评估决策；风险闸门未通过时直接返回等待。不执行下单。
  4. 下载记录
    完成后导出 JSON。刷新页面会清除导入数据和结果。网页版暂不支持 MT5、自动监控或云端历史。
模型调用会消耗 Gateway 配额。两阶段分析有时间限制；失败不会生成假结果。
