2026-11-07。本版本基于桌面版 1.68.4，发布到 `codex/desktop-learning-multimarket-20261107`。`main` 网页版不包含本次提交，桌面分支保留 `git.deploymentEnabled=false`。

## Codex 模型与速度

原实时面板直接读取 API 配置，因此本地 Codex 分析也会显示残留的 DeepSeek 名称、推理设置和上下文额度。本版本通过 Codex 本地协议读取实际模型、推理强度、上下文配置和速度，在面板及分析记录中保存使用值。无法识别时显示本地 harness 状态，不使用 API 配置代替。

在「AI 模型设置 → 本地 Codex → Codex 速度」选择：

- **跟随 Codex 设置**（默认）：使用现有 Codex 速度。
- **标准**：为这次 PA Agent 调用选择标准服务速度。
- **Fast**：为这次调用选择 priority；额度消耗更高，可用性取决于模型和账户。

速度选择不改写全局 Codex 配置，也不改变模型或推理强度。此轮真实分析使用 **gpt-6-astra / max / 标准**。Fast 已验证配置保存和命令传递，本轮没有执行 Fast 的额外模型计费对比。

参考：[OpenAI 速度设置](https://learn.chatgpt.com/docs/agent-configuration/speed)、[模型和推理用量说明](https://help.openai.com/en/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex)。

## 3000 根完整分析的测量

将两张固定宽度表转换为制表符分隔数据：保留全部 3000 根、28 列数值和几何特征，逐单元格一致；保留两个分析阶段及原策略要求。Codex 调用还省去与行情分析无关的项目文档和插件初始化，并明确保留已识别的模型配置。

字符数比较只改变表格排版；实际调用还包含运行时消息，因此两种计数略有不同。实际输入减少 **21.4%**。耗时减少约 **1%**，是一次历史记录与一次重放的观察值，模型服务负载及生成内容未受控，尚未看到显著总时长改善。保留 Astra/max 时，主要等待仍发生在模型推理阶段。

重放返回两个完整 JSON 阶段，既有校验通过、无异常、无格式重试。无损输入证明原始信息得以保留；交易预测效果需要随后真实走势持续核验。此重放用于固定输入的性能比较；旧记录的 TradingView 时间偏移不回写，重新获取的数据使用修正后的 UTC 时间。

可复算脚本：`scripts/benchmark_analysis_input.py --record <旧记录.json> --output <报告.json> [--tokens]`。原始私人记录、配置、账户信息不随发行包上传。

## 自动增量复盘

在「其他通用设置」中开启「自动增量复盘」，并使用主窗口持续跟踪 / 增量分析。菜单「增量复盘」可以查看各组进度、经验版本和导出 JSON。

1. 分析成功完成时冻结本轮方向、完成时间、当时实际报价和最新已收盘 K 线位置。
2. 下一轮增量分析使用新增已收盘 K 线的末价，与上一轮完成时的报价比较。模型思考期间已经收盘的 K 线排除在未来表现之外。
3. 按数据源、交易所、品种、周期、复权口径分组。5m 与 1h 分开累计；不同交易所的同名代码也分开。
4. 连续 **10 次有效比较**后形成一版统计经验，每再满 10 次保存新版本。不是要求连续预测正确 10 次。无新收盘、重复快照、缺少同时点报价不增加样本；新完整分析开始新批次。
5. 后续同组增量分析读入已形成的经验，提示关注反复出现的偏多 / 偏空错误；原始行情、当前规则和决策校验继续执行。经验内容和引用版本写入分析记录及「策略选择与参考经验」导出环节。

方向优先来自下一根 K 线预期，其次下一周期预期，最后使用诊断方向并明确标记比较依据。涨跌判别采用上一轮 ATR 的 0.15 倍作为中性带。10 次是开始总结的门槛，后续继续累计实际表现。

这是本地、可检查的复盘记忆和提示反馈机制。当前版本不训练模型权重。历史记录缺少完成时的报价，不能补算为新功能的真实连续样本；安装后从新分析开始积累。复盘使用 SQLite 索引，避免每轮扫描大型历史 JSON。

## AlphaGPT 的实现与多市场支持

[原 AlphaGPT](https://github.com/williamjjj/AlphaGPT) 的核心为 Transformer 生成公式 token、栈式虚拟机计算因子、回测给出奖励，再用策略梯度优化公式生成器，另有 LoRD 路径。PA Agent 本地版延续已集成的轻量研究引擎：因果因子 → 有预算的 RPN 公式搜索 → 时间顺序训练 / 验证 / 测试。搜索次数和种子固定，候选选择不读取测试区间；桌面版不加载原项目的 GPU 神经网络训练器。

「AlphaGPT 量化研究」可直接使用主图快照，也可通过当前 PA 数据源后台取得另一个品种、周期或根数，仍支持 CSV 和历史结果。

- 市场：虚拟币现货、股票 / ETF、期货 / 永续、外汇 / 贵金属。
- 周期：1/3/5/10/15/30/45 分钟；1/2/4/6/8/12 小时；1/3 日；1 周。具体可获取周期取决于数据源。
- 股票：多头 / 现金；数量步长可设置为 1 股、100 股等。
- 期货及外汇：多头、空头或双向；设置数量步长和合约乘数。
- 按实际交易 K 线推进，不填造休市数据；信号产生后在下一根实际 K 线开盘执行。零成交量 K 线不假设成交。
- 因子：收益、量能、蜡烛压力代理、均价偏离等。流动性/FDV 缺少历史数据时仍显示不可用。

回测采用 1 倍名义敞口，计入配置的费用与滑点。股票复权、连续期货换月沿用数据源；尚未模拟保证金、资金费、T+1、涨跌停排队和真实交易日历。休市与源数据缺口在无日历时标为未分类，不据此制造收益。

真实验证：TradingView QQQ / NASDAQ / 5m **3000 根**完成 **32 个候选**公式搜索；ES1! / CME_MINI / 1h **3000 根**完成历史回测。两者各按 1800 / 600 / 600 根划分训练、验证、测试。此轮 TradingView 登录请求退回公开行情连接，仍取得完整 3000 根；不将其记录为账户登录验证。

额外修复：tvDatafeed 使用主机本地时间的 `datetime.fromtimestamp`，原适配器错误地当成 UTC，在 UTC+8 机器上偏移 8 小时。现在按原时间语义还原 epoch，并用冬夏日期和真实行情验证。

安装版与绿色版均保留本机已有配置和历史。新增复盘库位于各自数据目录的 `learning/reviews.sqlite3`；发布包不包含用户数据。

本轮相关回归测试 **256 项通过**，涵盖真实模型标签、速度参数传递、3000 根输入逐单元格一致、10 次连续复盘及时间隔离、GUI 当前行情直用、股票/期货/外汇的分钟/小时/日/周研究、因果因子和留出测试集。修改文件的执行错误级静态检查通过。
