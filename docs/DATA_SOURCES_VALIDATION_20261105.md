## 本轮实测修复

安装程序原先使用 `data\*` 排除用户数据，也误排除了 AkShare 包内的 `data/calendar.json` 等资源，导致安装版国内期货读取失败。改为仅匹配发行目录根部的 `\data\*`，重建安装程序、重新安装后，期货读取通过。绿色版原本已包含这些资源。

自定义行情与 Yahoo Finance 的虚拟币代码不会再被黄金默认值迁移覆盖。切换到连接失败的数据源时，保留原数据源和品种/周期。MCP 的工具注解含默认值，查询调用按用户明确选择的工具执行，避免将缺少只读注解的正常资讯工具误拒绝。
